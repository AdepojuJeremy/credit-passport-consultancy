## Design-system guidance retained from the longer deck

Use the detailed front-end/design-system deck for:

- Manrope display typography
- JetBrains Mono numeric/technical typography
- neutral-first layouts
- generous whitespace
- 8pt spacing logic
- accessibility and visible focus states
- minimum 44px touch targets
- reduced-motion support
- restrained motion durations
- explainability, calm confidence and trust-oriented interaction principles

The longer deck also specifies Deep Teal as a primary color. That color is not treated as the consultancy website's canonical brand primary in this pass because it conflicts with the supplied current logo/brand palette. Revisit only if the team explicitly chooses the teal system as the new brand direction.
